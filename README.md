- Cadastro de empresas

## Tecnologias

- Java
- JSP e Jakarta/Java Servlets
- HTML, CSS e JavaScript
- MySQL
- Apache Tomcat
- Eclipse IDE

## Organização

Cada pasta representa um exercício ou projeto independente, com sua própria estrutura web e arquivos de configuração.

## Como executar

1. Instale o JDK e o Apache Tomcat.
2. Importe no Eclipse a pasta do exercício desejado como projeto web.
3. Ajuste as configurações do banco de dados quando o exercício utilizar persistência.
4. Adicione o projeto ao servidor Tomcat e execute.
5. Acesse a URL informada pelo Eclipse no navegador.

O projeto `agenda` inclui o script `agenda/agenda.sql` para criação do banco.
